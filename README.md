# Wentian Li — Personal Website

An English academic and professional portfolio featuring robotics and software projects, published research, education and work experience.

Website: https://leowinter15.github.io/

## Edit the website

- `index.html` — biography, projects, publication, experience and contact details.
- `styles.css` — layout, typography, colours and responsive styles.
- `script.js` — mobile navigation and expandable publication citation.
- `assets/wentian-li.jpg` — portrait.
- `assets/Wentian-Li-CV.docx` — downloadable CV.

Open `index.html` in a browser for a local preview. No installation or build step is required. Assets are local, with no external fonts, analytics or third-party scripts.

## GitHub Pages

Publish from the `main` branch and the repository root (`/`). The `.nojekyll` file enables plain static-file publishing.
